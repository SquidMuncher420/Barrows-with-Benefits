Better Barrows text consistency update

- Better Barrows-owned overlay text now uses Java's logical SansSerif font for
  a clean, readable, Arial-like appearance across supported operating systems.
- Brother/mound labels use SansSerif Bold 12.
- Helper/HUD overlay text uses SansSerif Plain 12.
- RuneLite's native plugin configuration panel controls (setting labels, number
  spinners, hexadecimal colour fields, checkboxes and Reset button) are created
  by RuneLite itself. A Plugin Hub plugin cannot safely replace their font.
  Therefore these files deliberately do not hack or globally alter RuneLite UI fonts.
- All previous player-style NPC outlines, five-second tunnel fallback, door/puzzle
  highlighting and other Better Barrows behavior are retained.
