BETTER BARROWS - THANK YOU, CREDITS, AND LICENSING

WHY THIS FILE EXISTS

Better Barrows was not created in a bubble.

I am a junior developer and vibe coder.

Being able to read other open-source RuneLite projects helped me learn.

I want to clearly thank those developers and also explain the important difference between:

Being inspired by somebody's idea.

And:

Copying or adapting somebody's source code.

Those are not the same thing.


WHAT IS A SOFTWARE LICENCE?

A software licence is a set of rules from the person or people who own the code.

It explains what other people are allowed to do with that code.

Open source does NOT mean:

"Do anything you want and remove everybody else's name."

Different open-source licences have different rules.

If Better Barrows directly uses somebody else's code, we need to follow the licence attached to that code.

WHAT IS BSD 2-CLAUSE?

BSD 2-Clause is a permissive open-source licence.

In simple terms, it allows people to use and modify the covered code, but it still requires important copyright/licence information and the disclaimer to be kept when redistributing covered code.

So:

"Open source"

does not mean:

"Delete the original credit."

This is why Better Barrows keeps a third-party notices file.


INSPIRATION IS DIFFERENT FROM COPYING CODE

Imagine you see another plugin that highlights a door.

You think:

"That is a useful idea. I want my plugin to highlight doors too."

Then you write your own implementation.

That is different from opening their Java file, copying their code, changing a few names, and putting it into your project.

The second situation involves their source code and therefore its licence matters directly.

Better Barrows should be honest about both kinds of influence.
