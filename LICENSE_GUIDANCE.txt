BETTER BARROWS - LICENCE GUIDE

WHAT IS A LICENCE?

A software licence tells other people what they are allowed to do with your code.

Before Better Barrows is publicly released, the repository should contain a file named:

LICENSE

RuneLite's Plugin Hub documentation recommends the BSD 2-Clause "Simplified" licence for plugin repositories.

The final licence needs the correct copyright holder and year.

Do not guess somebody's legal name.

The project currently uses the public developer name SquidMuncher420 in its plugin metadata.


WHAT ABOUT OTHER PEOPLE'S CODE?

Your Better Barrows licence covers code that you have the right to license.

It does not erase another developer's copyright.

If Better Barrows directly copies or adapts code from another project, read that project's licence and keep any notices it requires.

THIRD_PARTY_NOTICES.txt explains the known inspirations and current licence information.


BEFORE RELEASE

Make sure:

Better Barrows has its own LICENSE file.

The copyright holder information is correct.

THIRD_PARTY_NOTICES.txt is current.

Any copied/adapted third-party source has been checked.

Required third-party copyright and licence notices have been kept.


IMPORTANT

This document is practical project guidance, not legal advice.
