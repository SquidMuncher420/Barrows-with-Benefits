Barrows with Benefits is an all-in-one Barrows plugin — brother tracking, tunnel detection, kill tracking, navigation, puzzle help, and chest loot info, all in one place instead of spread across multiple plugins.

- Pick the order you want to kill the brothers in, and a hint arrow points you to the next mound. No more trying to remember who's left.
- Mounds and crypts are highlighted and colour-coded so you can see at a glance who's dead, who's alive, and which one's hiding the tunnel.
- Once the tunnel brother is found, the plugin remembers it for the rest of the run and automatically moves them to the end of your kill order.
- In the tunnels, it tracks kills toward whatever NPCs you're targeting (bloodworms, crypt rats, etc.) and highlights the ones you still need, so you're never guessing whether you've done enough.
- Your reward potential is shown right in the overlay, so there's no need to check it anywhere else.
- Want to get out fast? It'll draw the shortest route to the chest and only highlight the doors you actually need.
- Puzzle door pops up? The correct answer gets highlighted for you.
- Open the chest and it tells you exactly what you received — GE value, alch value, item breakdown — without counting items you already had in your inventory.

Every feature has its own on/off switch.

## How to Install

Available on the RuneLite Plugin Hub — search "Barrows with Benefits."

1. Open **RuneLite**.
2. Click the **spanner icon** in the top-right corner.
3. Click the **electrical plug icon** next to the two-person icon.
4. In the search bar, type **"Barrows with Benefits"**.
5. Click the green **Install** button.
